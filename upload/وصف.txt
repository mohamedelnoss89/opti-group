OptiSize - مركز صحة العين الشامل
تطبيق ويب متكامل لتفتيش صحة العيون وقياس المسافة البؤبؤية وتجربة النظارات افتراضياً، يعمل باللغتين العربية والإنجليزية بتصميم RTL وثيم داكن مستقبلي.

التقنيات
Next.js 16 (React 19, TypeScript) بوضع الإنتاج standalone
Tailwind CSS 4 مع أنماط Glass Morphism وتأثيرات Glow
Framer Motion للحركات والانتقالات بين الشاشات
FaceDetector API (أصلية المتصفح) + face-api.js (بديل CDN) ل كشف الوجه
Prisma + SQLite لقاعدة البيانات + localStorage للسجلات المحلية
الميزات الأساسية
الميزةش
التفاصيل
قياس PD	كاميرا مباشرة، 5 عينات، حساب أنثروبومتري (PD = 43% من عرض الوجه)، تصنيف: ضيق/طبيعي/واسع
حدة البصر	اختبار Snellen بـ 5 مستويات أحرف عربية متناقصة (80px → 22px)، 4 اختيارات لكل مستوىa
اختبار الألوان	8 ألواح Ishihara مولّدة برمجياً بتقنية Bitmap Grid (5×7 بكسل)، تصنيف: سليم/ضعف
الاستيجماتيزم	3 اختبارات SVG (ساعة، أقواس، شبكة) + 4 أسئلة أعراض
فحص الحول	3 أنماط بصرية + 6 أسئلة أعراض → تقييم خطر
المياه البيضاء	3 أشكال بضباب تدريجي + 7 أسئلة → تقييم خطر
المياه الزرقاء	محاكاة مجال رؤية (20 نقطة طرفية) + 7 أسئلة → تقييم خطر
معرض النظارات	68 نموذج في 5 فئات، 12 نوع إطار، 70 صورة، بحث + فلاتر + ترتيب
تجربة افتراضية	كاميرا/رفع صورة → كشف وجه AI → سحب + تكبير (0.3x-2.5x) + دوران (-30°/+30°) → تحميل PNG
السجلات	حفظ تلقائي لكل فحص في localStorage، عرض، حذف، مسح الكل
ثنائي اللغة	317+ مفتاح ترجمة عربي/إنجليزي، تبديل فوري RTL/LTR

البنية
21 مكوّن React مخصص (src/components/optisize/) بإجمالي 10,060 سطر
6 مكتبات مساعدة (src/lib/): i18n, storage, auth, faceDetection, pdCalculation, glassesFaceDetection
4 API Routes: auth, measurements, generate-glasses-image, health check
آلة حالات بـ 17 state تُدار من page.tsx مع AnimatePresence
دعم الضيوف مع تنبيه تسجيل الدخول
