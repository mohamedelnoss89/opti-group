# 🚀 تعليمات رفع بوت OptiSize على Replit (مجاني بدون فيزا)

## الخطوة 1: إنشاء حساب Replit
1. روح على https://replit.com
2. اعمل حساب مجاني (بالجيميل أو الجيت هوب)
3. **مفيش حاجة فيزا!**

## الخطوة 2: إنشاء Repl جديد
1. اضغط على **+ Create Repl**
2. اختار Template: **Node.js**
3. سمّيه: `optisize-bot`
4. اضغط **Create Repl**

## الخطوة 3: رفع الملفات
1. امسح كل الملفات اللي في الـ Repl (index.js و non-existing files)
2. ارفع الملفات دي:
   - `index.js` (كود البوت الرئيسي)
   - `package.json`
   - `.replit` (إعدادات التشغيل)
   - `replit.nix` (إعدادات النظام)
   - `.env` (المتغيرات السرية)
   - `.gitignore`
3. أو ببساطة: اسحب مجلد optisize-replit كله وافلته في Replit

## الخطوة 4: تثبيت المكتبات
1. افتح الـ Shell (من الـ sidebar على الشمال)
2. اكتب:
```
npm install
```
3. استنى لحد ما يخلص

## الخطوة 5: تشغيل البوت
1. اضغط على زر **Run** الأخضر
2. البوت هيبدأ وهيظهر QR Code في صفحة الويب
3. افتح الرابط اللي هيظهر فوق (https://optisize-bot.اسمك.repl.co)

## الخطوة 6: ربط الواتساب
1. افتح الرابط في المتصفح
2. امسح الـ QR Code من واتساب:
   - واتساب > الإعدادات > الأجهزة المرتبطة > ربط جهاز
3. أو استخدم **Pairing Code** (هيظهر في الصفحة وفي الكونسول)

## الخطوة 7: تشغيل 24/7 (مهم جداً!)
### الطريقة 1: Replit Always-On (الأسهل)
1. بعد ما البوت يشتغل، روح على **Deployments** في الـ sidebar
2. اضغط **Set up your deployment**
3. اختار **Autoscale** (المجاني)
4. اضغط **Deploy**
5. البوت هيفضل شغال 24/7!

### الطريقة 2: UptimeRobot (الاحتياطية)
1. لو مش عايز تعمل Deploy، استخدم UptimeRobot عشان تمنع البوت ينام:
2. روح على https://uptimerobot.com
3. اعمل حساب مجاني
4. أضف Monitor جديد:
   - نوع: HTTP(s)
   - الرابط: https://optisize-bot.اسمك.repl.co/status
   - كل: 5 دقائق
5. ده هيبيند الرابط كل 5 دقايق فالبوت مينامش

## ⚠️ ملاحظات مهمة:
- **لازم تعمل Deploy أو تستخدم UptimeRobot** عشان البوت يفضل شغال. لو مسبتش حاجة منهما، Replit هينوم البوت بعد 5 دقايق من عدم الاستخدام.
- **auth_info** المجلد ده فيه بيانات الجلسة. لو مسحته هتحتاج تمسح QR تاني.
- **Gemini API Key** المجاني بيدد 15 طلب في الدقيقة و 1500 في اليوم - كفاية للاستخدام العادي.
- لو البوت فصل، Replit هيشغله تاني تلقائياً لو عملت Deploy.

## 🔧 استكشاف الأخطاء:
- لو البوت مش شغال: شوف الـ Console فيه أخطاء إيه
- لو الـ QR مش ظاهر: حدث الصفحة (F5)
- لو البوت بيفصل كتير: تأكد إن الـ Deploy شغال أو UptimeRobot شغال
- لو Gemini مش شغال: تأكد إن الـ API Key صح في ملف .env
